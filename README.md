# qa_python

В данном проекте реализован набор юнит-тестов для класса BooksCollector:

### Добавление и обновление книг:
1. test_add_new_book_new_book_added_successfully - проверяет добавление новой книги в коллекцию books_genre.
2. test_add_new_book_existing_book_shows_no_change - проверяет, что повторное добавление книги, которая уже находится в коллекции books_genre, не изменяет состояние коллекции.
3. test_set_book_genre_existing_book_genre_updated - проверяет обновление жанра у существующей книги.

### Получение информации о книгах:
4. test_get_book_genre_existing_book_returns_genre - проверяет корректность возвращаемого жанра у существующей книги.
5. test_get_books_with_specific_genre - проверяет фильтрацию коллекции books_genre по указанному жанру.</br>
Тест учитывает кейсы, когда:
   - найдена одна книга;
   - найдено несколько книг;
   - не найдено ни одной книги.
6. test_get_books_genre_all_books_returns_all_books_genre - проверяет корректность возвращаемой коллекции books_genre.
7. test_get_books_for_children - проверяет фильтрацию коллекции books_genre по книгам, доступным для детей.</br>
Тест учитывает кейсы, когда:
   - найдена одна детская книга;
   - найдено несколько детских книг;
   - не найдено ни одной детской книги.

### Работа со списком фаворитов:
8. test_add_book_in_favorites - проверяет добавление книги в список фаворитов:
   - успешное добавление существующей книги
   - отсутствие изменений при попытке добавить несуществующую книгу.
9. test_delete_book_from_favorites - проверяет удаление книги из списка фаворитов:
   - успешное удаление существующей книги
   - отсутствие изменений при попытке удалить несуществующую книгу
10. test_get_list_of_favorites_books_two_books_returns_list - проверяет корректность возвращаемого списка фаворитов.
